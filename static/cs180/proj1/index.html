01 / From exposures to RGB

Find the same scene in three channels.

The input is a vertically stacked grayscale scan ordered B, G, R. The height is divided by three (discarding at most two trailing rows), and each part is converted to float in [0, 1] using its integer type’s range. This preserves the 16-bit TIFF data. Blue is the reference; green and red are aligned independently to it.

For every candidate displacement, compare the same interior pixels in blue against translated pixels in the moving channel. The default similarity is mean-subtracted normalized cross-correlation (NCC):

NCC(A, B) = Σ[(A − mean(A))(B − mean(B))] / √[Σ(A − mean(A))² · Σ(B − mean(B))²]
Choose the displacement with the largest NCC.

Subtracting the mean reduces sensitivity to additive brightness changes; normalization removes uniform positive gain differences. It does not make different spectral responses identical. The implementation also supports L2 via mean squared error: minimizing it gives the same displacement as L2 on an equal-size scoring window. The results on this page use NCC.

A 10% border is excluded on each side of the reference channel to reduce interference from scanner frames. The moving-channel samples can approach their own frame when shifted; both channels are not independently cropped by this percentage. The scoring window is further restricted so every tested translation uses real source pixels. It remains fixed across candidates. Large windows are sampled regularly with a stride of ceil(longest interior side / 512); small images use every interior pixel. This is an explicit scoring approximation, while the search still refines at one original pixel per step.

Offsets throughout the report are (x, y) = (column shift, row shift), applied to G or R relative to B. Positive x moves right; positive y moves down. Internally NumPy uses (dy, dx). Final composition uses np.roll and removes the non-overlapping strips, so wrapped pixels never appear in the result. The remaining photographic borders are retained; this is not automatic border detection.

02 / Single scale

A small exhaustive search.

Two nested loops test every integer shift in [−15, +15] along each axis: 961 candidates per channel. This is practical for the small JPEGs, but a fixed small window cannot recover the much larger displacements in full-resolution scans.

03 / Coarse to fine

Full-resolution alignment with an image pyramid.

1. Reduce

Convolve each axis with [1, 4, 6, 4, 1] / 16, then keep every second pixel. Repeat until the shorter side is at most 256 pixels. The pyramid is implemented explicitly.

2. Search

At the coarsest level, search [−15, +15]. Large original displacements become small enough to fit inside this window.

3. Refine

Double the estimated shift when moving to the next finer level, then search a ±3-pixel neighborhood. Continue to the original resolution.

All provided TIFFs are processed at their original dimensions, with no initial resizing. Each finer level tests 49 candidates per channel instead of repeating a large exhaustive search. The same parameters are used for every image. Measured pyramid times range from 0.066 to 0.554 seconds for two-channel alignment and composition, excluding image loading and JPEG writing.

07 / What remains imperfect

Alignment is only part of restoration.

Emir is the clear raw-pixel alignment failure: the robe has different intensities across channels, misleading the NCC score. The remaining images have no obvious global misalignment in visual review, though local motion, scratches, and filter-dependent structure still cause fringes. The model uses integer translations and retains the photographic borders inside the shared overlap.
