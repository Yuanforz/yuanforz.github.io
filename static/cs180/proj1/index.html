01 / Method

Channel alignment

Split each plate into B, G, R and normalize to [0, 1]. Align G and R to B by maximizing mean-subtracted NCC.

NCC(A, B) = Σ[(A − mean(A))(B − mean(B))] / √[Σ(A − mean(A))² · Σ(B − mean(B))²]

A and B are the candidate and reference pixel windows. Subtracting their means removes constant brightness offsets; dividing by their norms removes positive contrast scaling. A higher score means closer agreement. All results below use raw-pixel NCC.

Exclude a 10% reference border to reduce film-edge interference. Within each search, score the same interior pixels for every candidate, keeping the window valid for all shifts. Large windows use stride ceil(longest interior side / 512) to reduce computation; shifts still have one-pixel precision.

Apply the estimated shifts with circular array shifts, then crop to the channels’ common valid overlap to remove wrapped pixels. Stack the aligned channels in RGB order.

Offsets: (x, y) applied to G/R relative to B. Positive x → right; positive y → down. Times exclude image I/O.

02 / Single scale

Exhaustive search

For G and R independently, test every integer shift within ±15 pixels of zero on each axis. Compare each shifted window with B and keep the highest NCC: 961 candidates per channel. This works for the small JPEGs, whose displacements fit inside the search window.

03 / Pyramid

Coarse to fine

Large scans need wider searches, whose candidate count grows quadratically with the radius. A pyramid makes large displacements small at coarse resolutions, then uses local searches to recover full-resolution precision.

1. Reduce

Smooth each axis with [1, 4, 6, 4, 1] / 16 to reduce aliasing, then take every second pixel. Repeat until the shorter side is ≤ 256 px.

2. Search

At the coarsest level, search ±15 pixels around zero using the same NCC procedure, independently for G and R.

3. Refine

Move to the next finer level and double both shift coordinates. Search ±3 pixels around that estimate (49 candidates). Repeat through the original resolution.
