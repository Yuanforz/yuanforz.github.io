1.1 — Convolutions from scratch

Flip the kernel in both axes, multiply each image window by it, and sum. The four-loop version sums pixel by pixel; the two-loop version uses a NumPy sum. Both return the input size with zero padding. For even kernels, the extra padding goes on the top/left to match SciPy’s same mode. Zero padding darkens the box-filter boundary and creates derivative responses at the image frame.

The input is my normal-perspective Proj0 portrait, converted to grayscale and resized to 192 × 256. The box kernel is ones((9, 9))/81; Dx = [1, 0, −1], Dy = Dxᵀ. Signed derivatives are displayed around mid-gray.

Convolution code
def _prep_conv(image, kernel):
    kh, kw = kernel.shape
    pad = np.pad(image, ((kh // 2, (kh - 1) // 2), (kw // 2, (kw - 1) // 2)))
    return pad, kernel[::-1, ::-1], np.zeros(image.shape)


def convolve_four_loops(image, kernel):
    pad, flip, res = _prep_conv(image, kernel)
    h, w = image.shape
    kh, kw = kernel.shape
    for y in range(h):
        for x in range(w):
            for ky in range(kh):
                for kx in range(kw):
                    res[y, x] += pad[y + ky, x + kx] * flip[ky, kx]
    return res


def convolve_two_loops(image, kernel):
    pad, flip, res = _prep_conv(image, kernel)
    h, w = image.shape
    kh, kw = kernel.shape
    for y in range(h):
        for x in range(w):
            res[y, x] = np.sum(pad[y:y + kh, x:x + kw] * flip)
    return res

1.2 — Finite difference operator

Convolve with Dx = [1, 0, −1] and Dy = Dxᵀ. The gradient magnitude is √(Ix² + Iy²); an edge is a pixel whose magnitude exceeds the threshold. Symmetric boundaries avoid artificial edges against a black frame.

I use 0.28: 0.16 retains more grass texture, while 0.40 loses weaker contours. The wider difference spans two pixels, so the thresholds are increased. The middle choice keeps the person and tripod while removing some weak responses; texture still appears because finite differences respond to rapid changes everywhere.

1.3 — Derivative of Gaussian

Build an 11 × 11 Gaussian with σ = 1.5 using cv2.getGaussianKernel and an outer product. Smoothing before differentiation suppresses fine texture. The resulting contours are thicker and less noisy, but some fine details disappear. Their lower magnitudes need a lower threshold (0.08).

Associativity gives (I * G) * Dx = I * (G * Dx). With one symmetric extension and valid convolutions, the maximum x/y error over the whole image is 1.51e-15. Both outputs retain the original image size. The displayed smoothed-difference and DoG magnitudes agree to floating-point precision.

2.1 — Image sharpening

Unsharp masking adds amplified high frequencies: S = I + α(I − G * I). Equivalently, use one convolution with (1 + α)δ − αG. The implementation uses this single kernel independently on R, G and B. Computation stays in floating point; only display clips to [0, 1].

Increasing α strengthens edges, but α = 3 also exaggerates texture and creates halos. On the deliberately blurred campus image, MSE relative to the original changes from 0.004495 to 0.003253. Sharpening restores some edge contrast, but cannot recover details removed by blur; it is not an inverse filter.

2.2 — Hybrid images

A hybrid adds a Gaussian low-pass image to a second image’s high-pass residual: H = GσL * A + (B − GσH * B). Close viewing reveals fine detail from B; at a distance, A’s broad structure dominates. Both frequency components retain RGB color; filtering is applied per channel.

Two manually chosen eye centers (or building landmarks) define a similarity transform. Each pair is rotated, uniformly scaled and translated to common landmarks, then cropped to shared valid coverage. The first image supplies low frequencies.

σL = 5, σH = 3 pixels at the aligned resolution. Open hybrid at full size.

I choose (5, 3): the smaller sigmas retain more competing facial detail, while (8, 5) makes the cat’s broader features dominate. Gaussian filters have no hard cutoff; their approximate half-amplitude frequency is √(2 ln 2)/(2πσ), giving 0.0375 and 0.0625 cycles/pixel for σ = 5 and 3. The low-pass spectrum concentrates around the center; subtracting the blur suppresses the high-pass center.

2.3 — Gaussian and Laplacian stacks

RGB channels are filtered independently. All stack levels keep the original dimensions. G0 = I; later levels blur I with σ = 1, 2, 4, 8, 16 pixels using separable Gaussian convolutions. Li = Gi − Gi+1, with the last Gaussian retained as the low-frequency residual. Summing all Laplacian levels reconstructs the original. No built-in pyramid function is used.

Fine edges appear in early Laplacian levels; broader intensity changes appear later. The final residual carries the smooth brightness structure. The masked (a)–(l) reconstruction is shown with the blend in Part 2.4.

2.4 — Multiresolution blending

Build Gaussian stacks for the mask and Laplacian stacks for both images. At each level, combine Mi · LAi + (1 − Mi) · LBi, then sum the bands and residual. The blurred masks make coarse transitions wider while preserving localized fine detail. The same two-dimensional mask is applied to each RGB channel, preserving the source colors.

The Oraple uses a vertical step. The two custom blends use a gently curved left/right bridge mask and a wavy river boundary. Compared with a direct cut, low-frequency brightness changes are smoother. Blending does not solve semantic mismatches: the two bridges have different structures and viewpoints, so this is a cross-city composite; unrelated landscape structures still meet.

The most important thing I learned is that boundaries and frequency bands matter together: smoothing suppresses noisy derivatives, sharpening boosts existing detail, and blending needs a smooth mask at every frequency scale.
