1.1 — Convolutions from scratch

Flip the kernel, multiply each window by it, and sum. Four loops process individual products; two loops use a NumPy sum per window. Zero padding preserves the input size (same mode), but darkens blurred borders and creates derivative responses at the frame.

My grayscale portrait is 192 × 256. Box = ones((9, 9))/81; Dx = [1, 0, −1], Dy = Dxᵀ.

Convolution code
def _prep_conv(image, kernel):
    kh, kw = kernel.shape
    pad = np.pad(image, ((kh // 2, (kh - 1) // 2), (kw // 2, (kw - 1) // 2)))
    return pad, kernel[::-1, ::-1], np.zeros(image.shape)


def convolve_four_loops(image, kernel):
    pad, flip, res = _prep_conv(image, kernel)
    h, w = image.shape
    kh, kw = kernel.shape
    for y in range(h):
        for x in range(w):
            for ky in range(kh):
                for kx in range(kw):
                    res[y, x] += pad[y + ky, x + kx] * flip[ky, kx]
    return res


def convolve_two_loops(image, kernel):
    pad, flip, res = _prep_conv(image, kernel)
    h, w = image.shape
    kh, kw = kernel.shape
    for y in range(h):
        for x in range(w):
            res[y, x] = np.sum(pad[y:y + kh, x:x + kw] * flip)
    return res

1.2 — Finite difference operator

Ix = I * [1, 0, −1]; Iy uses the transposed kernel. Magnitude = √(Ix² + Iy²). Pixels above the threshold become edges. Boundaries use symmetric extension.

I choose 0.28: 0.16 retains too much grass texture; 0.40 loses weaker contours. Some texture remains at 0.28.

1.3 — Derivative of Gaussian

Use cv2.getGaussianKernel and an outer product to form an 11 × 11 Gaussian (σ = 1.5). Smoothing reduces texture noise but broadens contours and removes fine detail. The edge threshold is 0.08.

(I * G) * Dx = I * (G * Dx). Precomputing G * Dx gives one image convolution per direction. With identical boundary extension, the maximum one-stage/two-stage error is 1.51e-15.

2.1 — Image sharpening

Gaussian blur retains low frequencies. Subtract it to obtain high frequencies, then add them back with weight α: S = I + α(I − G * I). The equivalent single convolution kernel is (1 + α)δ − αG.

Larger α sharpens edges but introduces halos at α = 3. After deliberate blur, resharpening reduces campus-image MSE from 0.004495 to 0.003253. Edge contrast improves, but lost detail is not fully recovered.

2.2 — Hybrid images

H = GσL * A + (B − GσH * B). Low frequencies from A dominate at a distance; high-frequency detail from B dominates nearby.

Manually selected eye centers or building landmarks define rotation, uniform scaling and translation. Crop both aligned images to shared valid coverage.

I choose σL = 5, σH = 3. Smaller values retain competing facial detail; (8, 5) lets broader cat features dominate. Low-pass energy concentrates near the frequency origin; the high-pass filter suppresses that center.

The portrait change is subtle because both inputs show the same person. The building hybrid is less successful: incompatible tower positions leave overlapping rooflines.

2.3 — Gaussian and Laplacian stacks

G0 = I; subsequent Gaussian levels use σ = 1, 2, 4, 8, 16 without downsampling. Li = Gi − Gi+1; the last level retains the coarsest Gaussian. Summing all Laplacian levels reconstructs I.

Early bands contain fine detail; later bands contain broader structure. The final residual retains low-frequency brightness.

2.4 — Multiresolution blending

Blend each Laplacian level as Mi · LAi + (1 − Mi) · LBi, then sum all levels, including the residual. Mi comes from a Gaussian stack of the mask, giving wider transitions at coarser scales.

Oraple uses a left/right split; the bridges use a top/bottom split (Bay Bridge above, boundary at 62% height). The river blend uses a curved mask. Blurring the mask reduces abrupt color transitions, but cannot remove differences in viewpoint and structure.

What I learned: different frequency bands need different transition widths; a Gaussian mask stack smooths brightness changes while keeping fine detail localized.
